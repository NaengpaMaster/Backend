# 장보기 정책

## 장보기 목록

- 회원은 장보기 항목을 추가하고 구매 완료 여부를 체크하거나 항목을 삭제할 수 있다.
- 장보기 재료는 사전 재료 목록에서 검색하여 선택한다.
- 수량은 한 글자 이상 입력해야 한다.
- 카테고리는 선택한 재료의 카테고리로 자동 설정된다.
- 회원은 본인의 장보기 항목만 조회, 수정, 삭제할 수 있다.
- 장보기 목록이 비어 있으면 빈 목록 안내를 표시한다.

## 냉장고 반영

- 구매 완료로 체크한 본인의 장보기 항목만 냉장고에 반영할 수 있다.
- 이미 냉장고에 반영된 장보기 항목은 중복 반영하지 않는다.
- 장보기에서 냉장고로 반영된 재료의 기본 유통기한은 `기한없음`이다.
- 유통기한은 냉장고 관리 화면에서 직접 수정할 수 있다.
- 보관 위치는 장보기 냉장고 반영 과정에서 입력하지 않는다.

## 외부 구매 연결

- 외부 쇼핑 서비스로 이동하는 기능이 있더라도 실제 구매 완료 여부는 제휴사 전환 데이터가 있을 때만 확인할 수 있다.
- 챗봇은 외부 쇼핑 서비스의 주문, 결제 또는 배송 상태를 확인할 수 없다.
