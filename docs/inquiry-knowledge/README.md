# 냉파마스터 Q&A 지식 문서

이 디렉터리의 문서는 문의 Q&A 챗봇이 사용자 질문에 답할 때 사용하는 정책 원본이다.

## 답변 원칙

- 문서에 명시된 내용만 답변한다.
- 회원별 냉장고, 문의, 점수 등 개인정보를 추측하거나 대신 조회하지 않는다.
- 문서로 확인할 수 없는 내용은 추측하지 않고 관리자 문의 등록을 안내한다.
- 관리자 전용 기능을 일반 회원이 사용할 수 있다고 안내하지 않는다.
- 정책과 실제 서비스 동작이 다르면 실제 구현을 확인한 뒤 문서를 갱신한다.

## 문서 목록

- `account-profile.md`: 회원가입, 로그인, 권한, 프로필
- `fridge-expiration.md`: 냉장고 재료와 유통기한
- `recipe.md`: 레시피 조회, 추천, 등록
- `shopping.md`: 장보기 목록과 냉장고 반영
- `score-statistics.md`: 냉파 점수, 등급, 사용자 통계
- `inquiry.md`: 문의 등록, 수정, 삭제, 답변
- `notification.md`: 유통기한 및 문의 답변 알림
